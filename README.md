# DBMS Experiments

This repository contains 10 Database Management System (DBMS) experiments implemented using **MySQL** as part of my academic practical work.

## About the Repository

The purpose of this repository is to understand and practice SQL queries, database creation, table management, data manipulation, constraints, joins, functions, and database operations through practical experiments.

## Experiments List

| No. | Experiment Name | Topics Covered |
|---|---|---|
| 01 | MySQL Basics | Variables, data types, operators |
| 02 | SQL Commands | CREATE, USE, DROP |
| 03 | DDL and DML | CREATE, ALTER, INSERT, UPDATE, DELETE |
| 04 | SQL Filtering Operators | WHERE, BETWEEN, IN, LIKE, ORDER BY |
| 05 | SQL Functions | String, numeric, date and aggregate functions |
| 06 | SQL Constraints | PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK, DEFAULT |
| 07 | SQL Joins | INNER, LEFT, RIGHT, CROSS, SELF JOIN |
| 08 | Student Information System | Student, course and enrollment management |
| 09 | Supermarket Product Sales System | Product, customer and sales management |
| 10 | Library Management System | Books, members, issue and return management |


## Technologies Used

- MySQL 8.0
- SQL
- XAMPP
- phpMyAdmin

## How to Run

1. Install XAMPP on your computer.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Select the SQL tab.
5. Open the required `.sql` experiment file.
6. Copy and execute the SQL queries.

**Note:** Each experiment creates its own database. Running an experiment script again may delete and recreate that experiment's existing database.

## Learning Outcomes

- Understanding database concepts and SQL syntax.
- Creating and managing databases and tables.
- Performing data insertion, modification and deletion.
- Applying constraints to maintain data integrity.
- Retrieving data using SQL joins and filtering.
- Working with views and stored procedures.
